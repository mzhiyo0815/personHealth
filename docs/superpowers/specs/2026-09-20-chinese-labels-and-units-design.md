# 页面中文标签与单位设计

## 目标

将个人健康记录应用中所有面向用户的英文表单标签和操作文案改为中文，并在数值字段及历史、趋势展示中明确标注单位。保留 JSON、CSV 等必要的文件格式名称，同时补充中文说明。

## 范围

- 登录、注册、修改密码表单。
- 饮食、运动、力量训练、体重和腰围记录表单。
- 今日、历史、趋势和“我的”页面。
- Django 自动生成的力量训练删除复选框等可见文案。
- 数据导出入口文案。

不修改数据库字段名、导出文件字段名、URL 或既有数据结构，避免破坏兼容性。

## 文案与单位

- 时间统一显示为“记录时间”。
- 饮食字段使用“餐次”“食物”“份量/备注”“饱腹感（1–10）”。
- 热量使用“千卡（kcal）”。
- 蛋白质、碳水化合物、脂肪使用“克（g）”。
- 运动时长使用“分钟”。
- 负重、体重和目标体重使用“千克（kg）”。
- 腰围使用“厘米（cm）”。
- 力量训练使用“动作名称”“组数”“每组次数”。
- 训练强度、备注、目标设置和密码字段全部使用中文。
- 导出入口显示为“导出完整数据（JSON）”和“导出表格数据（CSV）”。

## 实现方式

在 Django 表单层显式设置中文 `label`，避免为了界面文案产生数据库迁移。身体指标的单位随“体重/腰围”类型变化，因此记录表单将使用通用标签“数值（体重 kg，腰围 cm）”，历史和趋势页面则根据类型显示精确单位。

力量训练内联表单集显式设置删除字段中文标签。登录、注册和修改密码沿用 Django 的校验逻辑，仅覆盖用户可见标签与帮助文本。

## 测试与验收

- 表单单元测试断言所有可见字段标签为中文且单位完整。
- 页面测试断言历史、趋势和导出入口显示正确单位与中文说明。
- 浏览器测试检查记录页不再出现已知英文标签。
- 运行完整 pytest 与真实 Chrome 回归，确认原有认证、CRUD、趋势、草稿和导出功能不受影响。
