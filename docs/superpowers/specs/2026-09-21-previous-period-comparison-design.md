# 上一周期比较设计规格

## 1. 目标

在趋势页为当前选择的 7 天或 30 天数据增加上一等长周期比较，帮助用户理解近期记录相对前一阶段发生了什么变化。

比较结果只陈述数据事实，不判断变化是“好”“坏”“正常”或“异常”，也不提供医疗建议。

## 2. 周期定义

- 当前 7 天：今天及之前 6 个本地自然日；上一周期为紧接其前的 7 个自然日。
- 当前 30 天：今天及之前 29 个本地自然日；上一周期为紧接其前的 30 个自然日。
- 两个周期长度相同、首尾相接且互不重叠。
- 所有边界沿用 `Asia/Shanghai` 本地日期，并以左闭右开时间区间查询。
- 无效的 `range` 参数继续回退到 7 天。

页面应明确显示“较前 7 天”或“较前 30 天”，避免用户误解为自然周或自然月比较。

## 3. 比较指标

### 3.1 体重和腰围

- 每个周期每天存在多条记录时，沿用现有规则，使用当天最后一条记录。
- 每个周期取最后一个有记录日期的值作为该周期代表值。
- 比较值为当前周期代表值减去上一周期代表值。
- 展示当前值、上一周期值和带正负号的绝对差值。
- 体重保留两位小数，单位为“千克（kg）”；腰围保留两位小数，单位为“厘米（cm）”。
- 任一周期没有该指标记录时显示“数据不足”，不跨越两个比较周期寻找更早记录。

### 3.2 运动分钟

- 分别汇总两个等长周期内的运动总分钟数。
- 比较值为当前周期总分钟减去上一周期总分钟。
- 展示当前总量、上一周期总量和带正负号的分钟差值。
- 没有运动记录视为 0 分钟，可正常比较。

### 3.3 力量训练次数

- 分别统计两个周期内运动类型为“力量训练”的运动记录数。
- 一条运动记录计为一次，不按力量动作明细数量重复计数。
- 展示当前次数、上一周期次数和带正负号的次数差值。
- 没有力量训练视为 0 次，可正常比较。

### 3.4 饮食记录完成率

- 沿用摘要卡口径：每天早餐、午餐、晚餐、加餐共四个可记录项，同一天同餐次多条记录只计一次。
- 分别计算两个周期的完成率。
- 差值为当前完成率减去上一周期完成率，单位为“个百分点”。
- 展示当前完成率、上一周期完成率和带正负号的百分点差值。
- 没有饮食记录时完成率为 0%，可正常比较。

## 4. 页面与交互

在现有“本期摘要”之后、趋势图之前增加“较上一周期”区域，包含五个紧凑比较项：

1. 体重；
2. 腰围；
3. 运动分钟；
4. 力量训练；
5. 饮食完成率。

每项突出显示差值，并在辅助文字中列出“当前 / 上期”数值。正值显式显示 `+`，负值保留 `-`，零显示 `0`。颜色仅用于层级，不使用红绿表达价值判断。

手机端采用单列紧凑列表，避免与现有五张摘要卡形成过密的双列信息墙；桌面端可使用两列。360 像素宽度不得产生横向滚动。

7 天/30 天切换继续使用现有链接，页面刷新后比较标题、周期数据和差值同步更新。

## 5. 架构与数据流

在 `tracker.services.trends` 中增加两个纯函数：

- 身体指标比较：输入当前周期和上一周期的日值序列，输出状态、当前值、上一周期值和差值；
- 一般数值比较：输入当前值、上一周期值和量化精度，输出两个值及差值。

趋势视图计算上一周期日期边界，将测量、运动和饮食查询的最早时间扩展到上一周期开始，然后按本地日期拆分成当前与上一周期数据。现有图表、营养趋势、摘要卡和自然周运动汇总仍只使用各自原有范围。

为避免查询数量成倍增加，每类记录使用一次当前用户范围查询，再在应用层按日期分区。所有查询必须从 `request.user` 的反向关系开始。

模板只显示服务层和视图已准备好的比较字典，不在模板内执行统计计算。

本功能不新增模型、字段或迁移。

## 6. 状态与边界处理

- 身体指标任一周期为空时状态为 `insufficient`，差值为 `None`。
- 行为类指标始终有数值，空周期按 0 处理。
- 饮食差值使用已经四舍五入为整数的两个完成率相减，保证页面上的当前值、上期值和差值算术一致。
- 数据恰好发生在周期开始时间时计入该周期；发生在下一周期开始时间时不计入前一周期。
- 当前周期和上一周期的数据分区必须互斥。
- 其他用户的数据不得影响任何比较值。

## 7. 测试策略

### 7.1 服务层单元测试

- 两个周期都有身体指标时计算正、负和零差值；
- 任一身体指标序列为空时返回数据不足；
- 一般数值比较正确保留指定精度；
- 0 与非 0 行为值可正常比较。

### 7.2 视图与权限测试

- 7 天和 30 天使用正确且不重叠的上一周期；
- 周期边界当天的数据归属正确；
- 运动分钟、力量次数和饮食完成率比较口径正确；
- 图表和本期摘要不被上一周期数据污染；
- 其他用户的数据不参与比较；
- 身体指标缺失状态正确。

### 7.3 浏览器验收

- 360、390、430 和 1280 像素宽度无横向溢出；
- 7 天和 30 天切换后标题与比较值同步变化；
- 数据不足文案可见；
- 比较含义不依赖颜色。

## 8. 不在本次范围

- 自定义日期范围；
- 自然周、自然月或同比比较；
- 营养摄入的上一周期比较；
- 百分比增长率；
- 趋势预测、目标建议或医疗解释；
- 邮件、推送或提醒。
